# AI 驯狗学院

一个让孩子用自然语言修改小游戏、试玩并继续改进的课堂工具。包含学生平板端、教师端和同步大屏；教师端带逐页教学提示。由一位家长从孩子的学习需要出发制作，创造力、表达和发现问题是课程目标，不代表已验证的教学效果。

## 启动

安装 Node.js 22 或更高版本，解压源码，进入项目目录：

```sh
npm start
```

无 npm 运行依赖，无需安装模型客户端。服务启动会在本机浏览器打开教师端和大屏。首次生成的教师/大屏随机口令保存在 **app/data/config.json**，该文件只能由部署者保管；不要截图或上传。若浏览器未自动打开，访问 http://localhost:8080/teacher 并填写该文件中的 teacherKey。学生端访问 http://localhost:8080/。

## 使用自己的模型

教师端「设置」选择服务商，填写自己的 API 基础地址、模型 ID 和 API Key，点击「保存」再「试一下」。可以选择「其他（OpenAI 兼容接口）」接自建服务；基础地址须包含服务要求的版本路径，程序追加 /chat/completions。模型名以自己的服务商账户可用列表为准；「列出可用模型」需要服务支持 /models，也可手填。

密钥仅由服务端保存和调用，配置查询只返回是否已配置，不回传密钥片段。学生和大屏不能访问配置接口。项目不包含作者的 API、Codex/Claude 登录态、私人网关或付费额度。调用费用和限额由部署者自己的服务商账户承担。不兼容 Chat Completions 协议的原生接口需要自行提供兼容网关。

默认未配置模型时，AI 修改会明确报错。只有教师主动选择「演示模式」才使用规则模拟，三端显示模拟提示；真实接口失败不会静默改用模拟。单机 HTML 课件同样是规则模拟。

也可设置服务进程环境变量 XGXY_LLM_PROVIDER（custom）、XGXY_LLM_BASE、XGXY_LLM_MODEL、XGXY_LLM_KEY；这些值会写入服务端私有配置。示例 config.example.json 不含任何真实密钥，首次启动会自动生成访问口令。

## 三端开课

1. 教师端选择课程，按逐页提示调度。先用少量设备验证模型响应、翻页同步和作品保存。
2. 大屏由教师端提供的带独立大屏口令链接打开，不要分享教师链接。
3. 平板与教师电脑连同一 Wi-Fi，扫码加入。学生需要能直接访问教师电脑的局域网地址，localhost 只能供电脑自己用；换 Wi-Fi 后在教师端核对二维码地址。访客 Wi-Fi 的设备隔离可能阻止互连。
4. 默认使用名单及个人登录码。现场需要「扫码只输姓名」时，启动前设置 XGXY_NAME_ONLY_JOIN=1；这是可信课堂便利模式，同名不构成可靠身份认证，不建议用于开放互联网。

Windows PowerShell 名字入班启动示例：

```powershell
$env:XGXY_NAME_ONLY_JOIN='1'
npm start
```

端口默认 8080，可用 PORT 调整。防火墙只向课堂局域网放行需要的端口。公网部署应使用 HTTPS 反向代理、固定 publicUrl 和严格入班方式；publicUrl 在教师设置中填写，只接受部署者配置，不自动信任请求 Host。不要把服务端 app/data 作为静态目录公开。

## 数据和隐私

作品、姓名和对话保存在 app/data（可用 XGXY_DATA 指向其他私有目录）。学生向 AI 发指令时，相关游戏代码、指令和必要对话上下文会发送给你配置的模型服务；请在开课前向家长说明使用方式。课堂数据不属于源码，不要提交或公开。备份和保留期限由部署者自行管理。游戏在 sandbox iframe 中运行，但这不是对所有模型生成内容的教学或安全保证，教师应监督试玩。

## 开发与验证

源码页面模块在 src/，服务在 app/server.js，起始小游戏在 app/games。运行 npm run build 生成 app/public、共享服务模块及单机课件，修改源码后需重新生成。这些生成文件随源码发布，以便直接启动；npm run check 核对生成物一致。

```sh
npm run check
npm test
npm run test:security
npm run guard
```

测试使用隔离合成数据和本地假模型端点，不调用付费模型，不证明真实班级并发或所有设备网络已验收。临时数据在 .tmp/，不进入发布包。
